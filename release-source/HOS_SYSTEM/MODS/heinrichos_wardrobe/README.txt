HEINRICHOS WARDROBE
Version 1.0.8

Bestandteil der HeinrichOS Players Edition.

Die Wardrobe-Erweiterung enthält die von HeinrichOS verwendeten eigenen
Outfit-/Materialvarianten für die Garderoben-Funktion.

Enthalten:
- HeinrichOS-eigene Wardrobe-Daten
- deutsche und englische Lokalisierung
- Outfit-/Materialvarianten für die zugehörigen HeinrichOS-Looks

Nicht enthalten:
- Silver Lys Gear
- Cheat Mod
- Cheat Script Pack

Einige HeinrichOS-Garderoben-Looks referenzieren optionale Fremdmods.
Diese werden aus rechtlichen Gründen nicht mitverteilt und müssen bei Bedarf
direkt von den jeweiligen Originalseiten bezogen werden.
