WAS IST HEINRICHOS?
HeinrichOS ist ein lokaler Begleiter für Kingdom Come: Deliverance II.
Die App bündelt durchsuchbare Befehle, Gegenstände, Sets, Garderoben-Looks,
Würfel-/Farkle-Hilfen, Quests, Quellen und weitere KCD2-Informationen.

START
1. HeinrichOS.exe im Hauptordner starten.
2. „HeinrichOS starten“ wählen.
3. HeinrichOS öffnet sich lokal im Standardbrowser.

UPDATE
Der Update-Center-Ablauf ist technisch vorhanden und lokal geprüft.
Der öffentliche GitHub-Updatekanal ist in dieser Ausgabe bewusst noch deaktiviert.
Eine spätere Aktivierung erfolgt nur über eine gesonderte Release-Freigabe.

OFFLINE
Die HeinrichOS-Kernfunktionen arbeiten vollständig lokal.
Beim normalen Start werden keine Web-Ressourcen automatisch geladen.
Externe Quellenlinks und der Feedbackkanal benötigen nur dann Internet,
wenn diese Funktionen bewusst verwendet werden.

SPIEL / MODS
HeinrichOS selbst muss nicht in den KCD2-Spielordner installiert werden.
Viele Konsolenbefehle setzen jedoch die entsprechende KCD2-Konsole bzw.
einen externen Cheat-Mod voraus.

Im Paket enthalten:
- HeinrichOS Wardrobe 1.0.8
  Pfad: HOS_SYSTEM\MODS\heinrichos_wardrobe

Nicht mitgeliefert:
- KCD2 Cheat Mod
- Cheat Script Pack
- Silver Lys Gear
- fremde Lösungsbuch-PDFs

SILVER LYS
Diese fünf Garderoben-Looks benötigen Silver Lys Gear:
- SILVER LYS I – BLAU / SILBER / GOLD
- SILVER LYS II – WEISS / SILBER / GOLD
- SILVER LYS III – HOLY MOLY
- SILVER LYS IV – SLEEPY HOLLOW
- SILVER LYS – PEBBLES

Silver Lys Gear ist nicht im HeinrichOS-Paket enthalten und muss bei Bedarf
selbst von der Originalseite installiert werden.

FEEDBACK
Der Feedback-Button öffnet den öffentlichen HeinrichOS-Feedbackbereich auf GitHub.
HeinrichOS überträgt dabei keine Daten automatisch. Eine Meldung wird erst
veröffentlicht, wenn du sie auf GitHub selbst absendest.

HINWEIS
HeinrichOS ist ein inoffizielles Fan-Projekt und nicht mit Warhorse Studios
oder PLAION verbunden.
