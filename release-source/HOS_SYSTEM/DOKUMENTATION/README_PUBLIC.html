Was ist HeinrichOS?

HeinrichOS ist ein lokaler Begleiter für Kingdom Come: Deliverance II. Die App bündelt durchsuchbare Befehle, Gegenstände, Sets, Garderoben-Looks, Würfel-/Farkle-Hilfen, Quests, Quellen und weitere KCD2-Informationen.

Start

  1. HeinrichOS.exe im Hauptordner starten.
  2. „HeinrichOS starten“ wählen.
  3. HeinrichOS öffnet sich lokal im Standardbrowser.

Update

  1. Im HeinrichOS-Launcher auf „Update“ klicken.
  2. Lesen, was in der neuen Version geändert oder verbessert wurde.
  3. Mit „Ja“ bestätigen, wenn das Update installiert werden soll.
  4. HeinrichOS prüft und installiert das Update automatisch.
  5. Nach erfolgreicher Installation erscheint eine kurze Bestätigung.

Ist bereits der neueste Stand installiert, zeigt HeinrichOS dies direkt an. Bei einem Problem wird das Update gestoppt und eine verständliche Meldung angezeigt.

Hinweis zum Update-Center:
Der Update-Ablauf wurde lokal geprüft. Der öffentliche GitHub-Updatekanal bleibt in dieser Ausgabe bewusst deaktiviert und wird erst mit einer gesonderten Release-Freigabe aktiviert.

Offline-Nutzung

Die HeinrichOS-Kernfunktionen arbeiten vollständig lokal. Beim normalen Start werden keine Web-Ressourcen automatisch geladen. Externe Quellenlinks, der Feedbackkanal und der spätere öffentliche Updatekanal benötigen nur dann Internet, wenn du diese Funktionen bewusst verwendest.

Spiel / Mods

HeinrichOS selbst muss nicht in den KCD2-Spielordner installiert werden. Viele Konsolenbefehle setzen jedoch die entsprechende KCD2-Konsole bzw. einen externen Cheat-Mod voraus.

Im Paket enthalten ist nur HeinrichOS Wardrobe 1.0.8. Fremdmods werden nicht mitverteilt.

Silver Lys

Fünf Garderoben-Looks benötigen Silver Lys Gear: Silver Lys I–IV sowie Silver Lys Pebbles. Der Mod ist nicht enthalten und muss bei Bedarf selbst von der Originalseite installiert werden. Die betroffenen Karten und Detailansichten weisen darauf hin und enthalten einen Link zur Originalquelle.

Feedback

Der Feedback-Button öffnet den öffentlichen HeinrichOS-Feedbackbereich auf GitHub. Dort kannst du zwischen Fehler melden, Idee / Wunsch und Sonstiges Feedback wählen. HeinrichOS überträgt dabei keine Daten automatisch; eine Meldung wird erst veröffentlicht, wenn du sie auf GitHub selbst absendest. Zum Absenden ist ein GitHub-Konto erforderlich.
